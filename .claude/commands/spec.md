구글 드라이브에서 와썹하우스 명세서를 읽고, "$ARGUMENTS"와 관련된 내용만 찾아서 요약한다.

다음 순서로 진행한다:

1. Google Drive MCP를 사용해 와썹하우스 관련 문서를 검색한다.
   - 요구사항 명세서 (SRS)
   - API 명세서
   - 화면 설계서 또는 UI 명세서
   - 프로토타입 HTML (있다면)

2. "$ARGUMENTS"와 직접 관련된 섹션만 골라낸다. 전체 문서를 복사하지 않는다.

3. 아래 형식으로 요약한다:

---

## 기능 요약
(어떤 기능인지 2-3문장. 비즈니스 목적과 사용자 관점에서 설명)

## 요구사항 ID
(관련 FR / NFR ID 목록)
- FR-XXX-YY: 항목 설명
- NFR-YYY-ZZ: 항목 설명

## 기능 요구사항
(구현해야 할 항목을 bullet로. 우선순위 MoSCoW 기준 표시)
- [Must] 항목
- [Should] 항목

## UI / 화면 흐름
(어떤 화면이 필요한지, 어떤 순서로 동작하는지, 컴포넌트 구조 힌트)

## API 연동
(어떤 엔드포인트를 호출하는지, 요청/응답 구조)
- Method URL
- Request: 필드, 타입, 필수 여부
- Response: 반환 필드, 상태값

## 데이터 모델
(있다면: DB 테이블, 주요 필드, 연관 관계)

## 제약 조건
(권한, 예외 케이스, 비즈니스 규칙)

## 비기능 요구사항
(성능, 보안, 사용성 등 NFR 항목)

## 구현 고려사항
(미해결 항목, 운영 검토 필요 사항, 1차 릴리즈 우회 방안, 향후 확장 포인트)

---

관련 명세가 없다면 "명세서에서 관련 내용을 찾지 못했습니다"라고 알린다.
